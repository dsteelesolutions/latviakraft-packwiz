# LatviaKraft pack (auto-updating)

Minecraft 1.20.1 + Forge 47.4.23 modpack for the LatviaKraft server, published with
[packwiz](https://packwiz.infra.link). This repo only holds pack metadata, a few jars that
are not downloadable from Modrinth/CurseForge, `servers.dat` and a default keybind.

## Play
1. Install [Prism Launcher](https://prismlauncher.org).
2. Add Instance > Import > choose `LatviaKraft-Prism.zip` (ask the server owner for it).
3. Sign in with your Microsoft account.
4. Launch. Every launch syncs the mods from this repo automatically.

Pack URL: `https://raw.githubusercontent.com/dsteelesolutions/latviakraft-packwiz/main/pack.toml`
